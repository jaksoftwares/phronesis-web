PHRONESIS HOMESCHOOL
Logo Design, Construction & Variation Specification
1. Core Logo Direction

The primary identity should be an institutional academic emblem/seal.

The reference direction has the right fundamental character:

Circular institutional structure
Academic symbolism
Formal appearance
Central educational symbol
Strong sense of identity and belonging
Suitable for certificates and official documents

However, the final Phronesis logo should be cleaner, more deliberate and professionally vector-designed rather than simply reproducing the reference.

Design character:

Institutional • Academic • Timeless • Intelligent • Warm • Modern

It should feel appropriate on both a school certificate and a modern educational platform.

2. Recommended Logo Architecture

The identity should consist of several coordinated elements:

              PHRONESIS HOMESCHOOL
                     ↓
              INSTITUTIONAL SEAL
                     ↓
              CENTRAL SYMBOL
                     ↓
              GENESIS OF KNOWLEDGE

The exact wording around the seal should be finalized during the actual logo design stage.

The central symbol should communicate concepts such as:

Knowledge
Learning
Growth
Wisdom
Education
Light/illumination
Development

Avoid filling the logo with too many unrelated symbols.

3. Central Emblem

The central emblem is the most important design component.

A possible conceptual direction is to develop a refined combination of:

Book + emerging/growing form + light/knowledge

This would connect naturally with:

Genesis of Knowledge

and

Cream for Sprouting Minds

The symbolism should remain subtle.

It should not become a literal illustration of a plant growing out of a book unless the final concept proves visually strong.

4. Institutional Seal Structure

The circular structure should have a clear hierarchy:

        ┌──────────────────────┐
        │  PHRONESIS HOMESCHOOL│
        │                      │
        │       EMBLEM         │
        │                      │
        │  GENESIS OF KNOWLEDGE│
        └──────────────────────┘

Possible elements:

Outer ring

Institution name.

Inner ring

Supporting institutional wording or motto.

Centre

Primary educational symbol.

The seal must remain recognizable even when reduced substantially.

5. Typography Inside the Seal

Typography needs special attention because circular logos become unreadable very quickly.

Use a highly legible typeface with:

Strong letterforms
Good spacing
Controlled tracking
Excellent small-size reproduction

The internal seal typography does not necessarily need to use the same typography as the website.

The brand system can therefore have:

Digital typography: Inter
Editorial: Source Serif 4
Logo lettering: Custom/modified institutional lettering

That gives the logo more individuality.

7. Colour Variations

The logo should not exist in only one colour.

Create official variants:

Primary colour

Deep Blue direction.

Full institutional colour

Blue + Teal + restrained Gold.

One-colour dark

For documents and monochrome applications.

White/reversed

For dark backgrounds.

Black

For formal monochrome printing.

Emboss/deboss version

For:

Certificates
Premium stationery
Institutional seals
Physical materials
8. Scalability Requirement

This is critical.

The logo must work at:

16–24px

as well as:

500px+

Therefore, the designer should create simplified small-size versions, rather than shrinking the detailed seal indefinitely.

For example:

FULL SEAL
     ↓
SIMPLIFIED SEAL
     ↓
BRAND MARK
     ↓
FAVICON / APP ICON
9. Digital vs Institutional Versions

Do not force one logo to solve every problem.

Think of it as a logo family.

                 PHRONESIS
                     │
          ┌──────────┴──────────┐
          │                     │
    INSTITUTIONAL          DIGITAL SYSTEM
       IDENTITY                 │
          │              ┌──────┼──────┐
       Full Seal        Mark   Wordmark Lockup
          │
    Certificates
    Documents
    Official use

This gives Phronesis flexibility without losing identity.

10. Clear Space

The final brand guidelines should define a protected area around the logo.

For example:

        ← clear space →
      ┌─────────────────┐
      │                 │
      │      LOGO       │
      │                 │
      └─────────────────┘

No:

Text
Images
Borders
UI elements
Other logos

should intrude into that space.

The exact measurement should be derived from the final logo geometry.

11. Minimum Size

The final specification should define minimum reproduction sizes for:

Print
Website
Mobile
Favicon
Social media
Embroidery/merchandise

This should be tested physically and digitally rather than choosing arbitrary numbers.

12. Incorrect Logo Usage

The guideline should explicitly prohibit:

Stretching
Compressing
Rotating
Changing proportions
Random colours
Unapproved gradients
Adding effects
Adding shadows
Replacing typography
Rearranging components
Placing it on unreadable backgrounds
Cropping the official seal improperly
13. Relationship With the Brand Colours

The logo should connect to the colour system we established:

Deep Blue → institutional knowledge/trust

Teal → growth/progress

Gold → wisdom/achievement

But the logo should remain effective without colour.

That is an important test of an institution-grade identity.

If the logo only works when rendered in multiple colours, the underlying mark is not strong enough.

14. Construction & Technical Requirements

The final logo should be created as true vector artwork.

Master formats:

SVG
AI / EPS
PDF

Production formats:

PNG
JPG
WebP

The master artwork should contain:

Vector paths
Correct curves
Consistent geometry
Proper typography
No unnecessary raster elements
No embedded low-resolution images

16. Final Design Test

Before approving the logo, test it in these environments:

Website header
Mobile app icon
Certificate
Educational PDF
Teacher profile
Learner dashboard
Social media avatar
Letterhead
Presentation cover
Black-and-white printer
Small favicon

If the same identity remains recognizable across all of them, the system is working.

The key creative direction

I would brief the designer/generator with this:

Create an institution-grade academic emblem for Phronesis Homeschool, inspired by the formal circular seal structure of established educational institutions. Preserve the authority, dignity and symbolic character of the supplied reference, but redesign it as a clean, refined, original vector identity aligned with Phronesis's modern, intelligent, nurturing and progressive brand. The identity should communicate knowledge, growth, wisdom and education, connect naturally to “Genesis of Knowledge,” and remain highly recognizable across certificates, educational publications, web platforms, mobile applications and official institutional materials.

One important distinction: the supplied image should be treated as a visual direction/reference, not something to trace or reproduce. The final Phronesis emblem should be an original design with its own symbolism and geometry.
